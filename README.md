One original English sentence — an absurd clause buried deep inside a terms-of-service agreement — written by a Python 3 program (standard library only, no network).

## Entry

> The Company reserves the right to replace your reflection with a stock photo, without notice, compensation, or resemblance.

## Run

```sh
python3 main.py
```

This writes the sentence to `/output/entry.txt`.
